# CasePerfect
A static, dependency-free web app that guides and tracks an AML/KYC case end to end.

Open `index.html` in a browser. Files: `index.html`, `styles.css`, `app.js`.

Workflow: Intake → CDD (ID&V) → Screening → Risk assessment → Enhanced due diligence (only if high risk) → Decision & approval → Closure & monitoring.
Stages unlock sequentially once required checks are complete; cases, notes and an audit log are saved in browser localStorage, and can be exported/imported as JSON.
